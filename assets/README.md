# Cutlery Assets

This directory contains the logo and icon assets for the Cutlery project.

### Recommended Files & Formats:
- **`cutlery.png`**: High-resolution 512x512 RGBA image with transparent background (used by standard Linux application launchers, GNOME, and KDE).
- **`cutlery.svg`**: Scalable vector format for crisp rendering across custom DPI displays and UI themes.
- **`icons/`**:
  - `cutlery-16x16.png`
  - `cutlery-32x32.png`
  - `cutlery-48x48.png`
  - `cutlery-64x64.png`
  - `cutlery-128x128.png`
  - `cutlery-256x256.png`

Running `cutlery register-desktop` automatically installs these icons into standard FreeDesktop paths (`~/.local/share/icons/hicolor/...`) and updates the system icon cache.
